# ListenFlow — Natural Neural Text-to-Speech Reader

A mobile-ready web app and installable PWA inspired by Listen AI, powered by 300+ free Neural AI voices (with offline browser fallback) and real-time word-by-word read-along highlighting.

## Features
- **Universal File Import**: Drag and drop `.pdf`, `.docx` (Word), `.epub` (eBooks), `.txt`, `.md`, `.html`, or images/screenshots.
- **Website & Article Reader**: Paste any URL to strip ads/navigation and listen to the clean article.
- **Read What's On Screen**:
  - **1-Click Browser Bookmarklet**: Drag to your bookmarks bar to listen to selected text or the full article on *any* webpage (even behind logins).
  - **Screenshot / Image OCR**: Paste any screenshot (`Ctrl+V`) or upload a photo to extract text with Tesseract.js and narrate immediately.
  - **Android PWA Share Target**: Install on Android to share links or text straight from Chrome or other apps.
- **Natural AI Voices**: 300+ Microsoft Edge Neural voices across 60+ languages + instant preview + offline device voice fallback.
- **Synchronized Listening Experience**: Live word highlighting, auto-scroll, instant speed (`0.5×–3.0×`), pitch control, sleep timer, bookmarks, Dark/Sepia/Light themes, accessible typography, Media Session lock-screen controls, and **MP3 Audiobook Export**.

## Quick Start

```powershell
npm.cmd install
npm.cmd run build
npm.cmd start
```

Then open **http://localhost:3001** in your browser (or on your phone over your local network!).

For development with hot reload:
```powershell
npm.cmd run dev
```
